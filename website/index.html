A memory should be useful.
And accountable.

Memento keeps raw history and derived memories distinct. You can retrieve the useful detail without losing the conversation that supports it.

  1. 01 /

    Keep the original

    Native integrations capture conversation records. Imported histories use stable identities, so repeating an import doesn’t create another copy of the same event.

  2. 02 /

    Find the relevant detail

    Recall combines semantic search with exact source evidence. Personal and professional scopes help keep context focused. Unconfirmed candidates remain distinguishable from confirmed memories.

  3. 03 /

    See what changed

    Corrections and refinements preserve history, reasons and supporting quotes. Follow-ups are reactive markers—not an autonomous agent making promises on your behalf.

A public website. Not a public memory.

Private by architecture.
Not by wishful thinking.

Your memory service runs on your infrastructure. This website is an introduction: it does not expose a memory database, a search endpoint or an account portal.

Google Drive is an optional archive and recovery destination. Memento requests drive.file access for its app-accessible files, not blanket access to your Drive. Backups are requested by the owner, not silently scheduled.
