# Media save and captured attachments

Detail for [AGENTS.md](../../AGENTS.md). Caveman-compressed; every rule here is binding.

Use `memento media save FILE --agent HARNESS --scope personal|professional`, `memento media status JOB_ID --agent HARNESS`, `memento media get SHA256 --agent HARNESS --output NEW_FILE`. Save streams up to existing 1 GiB blob limit; retain its job ID + stable command ID for identical retries. Exact native `--quote TEXT --conversation-id ID` supplies conversational evidence; otherwise command records honest artifact-identity evidence, not fabricated user statement. Retrieval verifies checksum, refuses overwrite. MCP `remember` accepts uploaded media references + evidence, never inline binary.

Supported captured attachment references from native user/assistant/tool projections enter durable per-content registry; every source occurrence preserved. Bytes and valid reference may arrive in either order. Bounded historical discovery advances persisted cursor: no session re-import, no hydrating opaque native raw records. Excluded: hook/internal context, raw-storage artifacts. Existing media worker admits at most two automatic jobs, reuses complete representations with compatible decoder/model identity; no new daemon or language-model pass. `media.captured_attachments` separates waiting, ready, queued, indexed, failed work; its discovery cursor is global even in source-filtered status. Completeness limit remains: missing bytes or missing usable projected references.

Automatically captured media: internal unclassified scope; public save validation stays strict; scoped recall excludes unclassified files. Explicit scoped saves keep own evidence + classification. Captured recall uses active occurrence provenance, honors forgotten sources/targets, reads original dates across all active references, displays at most five. Automatic recall uses existing modality thresholds; can offer one file pointer in shared context budget, labeled `media reference` with original link and source/date when known. Never invents caption, never implies visual/audio facts or lessons were extracted. Bridge renderer needs normal client update; server indexing and explicit recall work independently. Existing event IDs, capture metadata unchanged.
