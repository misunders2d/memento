# Service: install, models, schema, threads, publication

Detail for [AGENTS.md](../../AGENTS.md). Caveman-compressed; every rule here is binding.

## Service (local Linux storage only)

Compose resource ceilings: `MEMENTO_CPUS`, `MEMENTO_MEMORY`, `MEMENTO_MEMORY_SWAP` in deployment's `.env` (defaults: 2 CPUs, 5 GiB RAM, 10 GiB combined RAM plus swap). All-CPU access: use host's logical CPU count. Preserve existing swap allowance when raising RAM; verify running container's effective limits separately from Compose config. Keep machine-specific settings private; do not raise every installation's defaults for local headroom request.

Default production service = Rust: Compose selects `Dockerfile.native`, which builds daemon + native owner/import tools with pinned ONNX Runtime + media libraries. Run one service process per data dir. Python >=3.12 still required for portable stdlib runner/processor, not native daemon. Rust checks: use pinned native build environment (`cargo test --locked --workspace`); API contracts remain `http://127.0.0.1:8765/docs`. Python `Dockerfile`/`pyproject.toml` remain explicit comparison/development path: `uv sync --extra media --extra embedding --extra drive`, `MEMENTO_EMBEDDINGS=1 uv run memento --data-dir ./python-development-data`, `uv run pytest -q`. Never point that Python service at a native database.

Fresh Compose installation (human/operator steps, not agent commands):
```sh
sudo install -d -o 10001 -g 10001 -m 0700 ./data
docker compose up --build -d
curl --fail http://127.0.0.1:8765/health
```
Wait for healthy real-model startup; first download needs network, disk space + any Hugging Face model access/license acceptance required by unchanged pinned full `google/embeddinggemma-2` profile. Native model identities: `crates/model/src/lib.rs`; `crates/server/src/bootstrap.rs` verifies published FP32 ONNX assets. Native startup also prepares existing text relevance scorer. Cache persists under `/data/models`. Do not substitute disabled embeddings for acceptance. Compose: dedicated UID/GID 10001, read-only root, 2 CPUs, 5 GiB RAM, 256 PIDs, dropped capabilities, `/tmp` tmpfs. Keep `data/` on local Linux storage (not NFS/SMB/FUSE); the agent must not share the service UID. Overrides: `MEMENTO_UID`, `MEMENTO_GID`, `MEMENTO_AGENT_UID`, `MEMENTO_DATA_DIR`, `MEMENTO_PORT`; optional `.env` or `MEMENTO_ENV_FILE`.

Native live DBs use schema header **5**. Existing Python headers 1/2/3 require explicit [offline import into a new directory](README.md#upgrade-a-python-instance-to-the-native-service) with native `memento-import` before starting Rust; preserve old instance + data for rollback. Do not run an in-place conversion, lower the header or let both instances accept writes. Native `data/search/` indexes disposable: rebuild from existing FP32 vectors without re-embedding; Hot readiness does not imply Cold readiness.

Opt-in `tests/memory_acceptance.py native-retrieval` acceptance requires launcher-owned fresh native instance, pinned models, private matching-instance manifest; never target production. It labels supplied-memory retrieval separately from extraction, consolidation, generated answers, native-hook delivery. Keep reports private, preserve observed failures, remove disposable instance after verification; see README development instructions.

Default: one CPU thread per inference lane: foreground recall can run alongside one background encoder without waiting for whole long document or oversubscribing two-CPU quota. Mutable model preprocessing stays serialized; float32 precision, prompts, revision, dimensions unchanged. Keep `OMP_NUM_THREADS=1` under this resource budget; raising it can make automatic recall miss its deadline during indexing. Larger CPU allowance: `MEMENTO_BACKGROUND_TEXT_THREADS` (1..8, default 1) raises intra-op threads for background text session only; foreground recall keeps own one-thread session. `MEMENTO_TEXT_SCORER_THREADS` (1..8, default 1) separately raises foreground recall text scorer's intra-op threads on larger CPU allowance, scores unchanged; keep 1 on two-CPU or shared hosts. Keep code defaults generic; per-machine values belong in deployment's private config. Measure recall latency + complete indexing throughput before changing it on a deployment.

Explicit text tokenized literally, including model control-token spellings; image/audio preprocessing stays native. One-time text-encoding upgrade re-encodes only affected legacy text vectors; raw history, vector IDs, ordinary text/media vectors unchanged. It makes affected failed units due again; only successful normal indexing resolves those failure records. Passage chunking uses same literal-token mode under shared preprocessing lock. Only communicated user/assistant messages chunked + vectorized, newest first by capture order: newly captured messages served before remaining backlog; episode chunked when walk reaches it, so `unprepared_episodes` drains at embedding pace; tool output, tool-call turns, hook context, developer instructions stay raw history reachable by literal search. Older vectors of excluded chunks deleted in bounded background batches after startup; following bounded pass deletes those now vectorless chunk rows + their index failures. Chunks recorded in `node_stats` or `query_feedback` (cited or shown) stay as `history` references; literal hit on removed chunk returns its episode with span window. At startup DDL-only `episode_chunks_no_DELETE_v2` trigger replaces unconditional guard without header change (older header-5 images never delete chunks), still refuses every other chunk delete. DB file shrinks only after owner's `compact`.

Shutdown finishes current indexing unit, commits completed vectors, leaves rest pending; does not drain whole batch before exit. Restart resumes that unfinished work.

Publication stays loopback-only; never expose this unauthenticated API publicly. On server: set `MEMENTO_ALLOWED_HOSTS=<machine>.<tailnet>.ts.net` in `.env`, recreate memory container with `docker compose up -d` to apply environment, then run `tailscale serve --bg 8765` (tailnet HTTPS enabled). Serve proxies to unchanged loopback listener; tailnet ACLs must restrict access to your devices. Router-wide admission trusts loopback names + `MEMENTO_ALLOWED_HOSTS` for Host + any browser `Origin` on every route; JSON POSTs require JSON media type; MCP host protection stays enabled; `/mcp/` = endpoint. On each laptop, ask native agent to connect using `https://<machine>.<tailnet>.ts.net/connect`; that private guide = canonical client bootstrap instruction. The agent must have neither sudo nor Docker-daemon access when human-review isolation matters.
