# Recall: automatic, step, context packing, ranking

Detail for [AGENTS.md](../../AGENTS.md). Caveman-compressed; every rule here is binding.

Automatic recall waits up to three seconds; responses return on arrival. Same request may continue in detached worker at most fifteen seconds: one active request per conversation, only latest pending human request kept. Replacement uses existing worker's remaining lifetime (can be short near expiry). Each current query keeps normal initial wait + priority: fresh nonempty current result supersedes older ready offer. Older offer = fallback only while current query still pending or healthy-empty; different queries never merged into one offer. Pi/OMP can offer completed result before next model request in that turn; pending-only local claim makes no HTTP request, uses cooperative 200-millisecond deadline checked before consuming result and immediately before commit. Expired claims roll back ready result, cache, notice, receipt together. One-second child-kill backstop leaves time to return committed offer. Those checks stop sixteen seconds after refresh starts; compaction preserves current offer + pending recall without new HTTP request. Codex uses separate native async `UserPromptSubmit` handler, bound to its exact `turn_id`, only after normal human hook trust. Ordinary synchronous Codex hooks defer transcript reconciliation to existing detached uploader, use short local-lock wait; temporary contention can omit provenance or recall for that turn. Already registered transcripts can retry via kicked uploader, later hook on that transcript or explicit upload; blocked first registration awaits later hook. Quote saves and compaction capture before their boundary. Missing async support, trust or turn identity -> next-human fallback stays; Claude/AGY use that fallback. Late context offered once, labeled with its original query, subject to existing five-minute expiry + shared context budget; cannot interrupt in-flight model request or create continuation. Pending work is not an outage. Terminal failure warns once; successful response, including healthy empty result, clears warning state. Failed same-query request may use context cached up to five minutes, but still warns; it is not proof that the connection is healthy. Background completion alone creates no exposure receipt or update notice; those belong to native context offer.

Each HTTP `GET /recall` writes one stderr `recall_timing` JSON line: per-stage microseconds, cheap counts (including `query_chars`/`context_chars` lengths), effort/automatic/limit/scope flags, final pass; never query, context, memory text or IDs. `explain=true` returns same object as `timings`; MCP output unchanged.

Autonomous tool work can trigger fresh recall for Pi/OMP and Claude via same single detached worker; human queries keep priority. Current reminder gets separate owner-approved 1,500-byte allowance, five-minute expiry. Project only tool/executable/operation names + shell structure; exclude argument values, paths, inline scripts, raw errors. Deduplicate equivalent queries and already offered memory ID/version pairs; use 30-second ordinary/10-second failure cooldowns. Still required: native conversation/turn identity, Stop/new human/session fences, processing suppression, untrusted-evidence labeling, atomic exposure/claim deadlines. Pi/OMP delivery is request-local, survives compaction; Claude uses PostToolBatch. Eight-tool native synthetic tests qualified Pi/OMP/Claude delivery + capture exclusion. Codex tool hooks have contract tests but still need human /hooks trust and native end-to-end qualification. AGY autonomous delivery remains disabled. Update/reinstall native integration and reload/fresh session before expecting this path; never grant native trust or force an agent continuation. These bounded checks do not qualify general retrieval quality.

Automatic context packs complete items or skips them, continuing through later items that fit; optional rationales use leftover bytes. Service marks truncated fact summaries with `text_truncated`; bridges omit them without `full_text`. Automatic `full_text` carries complete current facts, including bodies beyond 240-character summary (owner decision 2026-11-02), when whole rendering with source/connection framing fits 1,500 bytes; longer renderings and sensitive types stay withheld. No content-based secret detector is claimed. Human and step allowances stay separate. Deploy service before `memento agent update` on clients; this packing change adds no hook/trust definition. Explicit summaries stay bounded, MCP marks truncation; `history` supplies complete evidence. HTTP-only `explain=true` reports actual returned-row routes, gates, validation, ordering without changing retrieval or exposing rejected IDs.

Stored-memory period recall uses additive aware-ISO `memory_since` (inclusive) / `memory_until` (exclusive), with or without semantic query. Filter by latest known original source time of current eligible evidence (`source_occurred_at`), never import/storage/citation time; unknown dates do not match. Semantic and lexical eligibility restricted before top-k selection. Period-only results newest first; related context not period-ranked. Preserve existing raw `since`/`source` semantics; reject combinations with those filters or automatic recall. Agents resolve relative periods to explicit bounds; this is not historical/as-of reconstruction. Python comparison service rejects period filters; use native service.

Recall decay is ranking-only: age never excludes otherwise eligible memory from automatic or ordinary recall, including legacy age-archived rows. Query-time recency uses latest original `occurred_at` across complete current-version evidence and committed citation renewal, with existing 90-day half-life. Missing original dates have neutral age weight; capture, import, extraction, promotion times are not substitutes. Pins and `explicit_user` behavioral suggestions exempt from aging. Automatic context includes original source date when known, independently of citation renewal; stored assertions, evidence, world-validity intervals unchanged. Forgotten, rejected, superseded states retain existing exclusions. This does not establish task completion or solve every applicability mismatch.

Automatic context uses shared bounded budget for facts, conditional behavioral suggestions and at most one relevant media reference; empty result is valid. Named entities whose stored spelling (or reviewed merged alias) appears in current request anchor that context: at most two `entity_context` records, each with its type, scope and up to five existing one-hop connections (active edges for durable nodes; active pending relation candidates and unverified `candidate_entity_matches` name hints for pending entities), taking slots from same limit. Selection is exact token containment, never similarity, no name-length or language rules; unknown name anchors nothing. Each durable node and each pending candidate stays its own identity: same-spelled entries labelled with count and IDs, not merged; endpoint state, scope, forgetting apply to every rendered connection, including promoted endpoints. Pending same-type spellings not resolved to one person here; consolidation keeps that decision. Generalized suggestions use existing `experience` type and consolidation schedule, retain exact supporting evidence, distinguish inferred lessons from explicit user preferences. Current instructions take precedence. Lasting relevant corrections can revise or retire suggestion through existing history; no per-turn model call or separate learning service involved. Broad explicit recall stays available.
